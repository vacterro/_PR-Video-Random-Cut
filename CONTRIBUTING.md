# Contributing to PR Video Random Cut

Contributions are welcome! Please follow these guidelines:

## Reporting Issues
- Use GitHub Issues for bug reports and feature requests
- Include steps to reproduce bugs
- Describe your Premiere Pro version and OS

## Pull Requests
- Fork the repository
- Create a feature branch
- Make your changes
- Test thoroughly in Premiere Pro
- Submit a pull request with a clear description

## Code Style
- Follow existing ExtendScript and JavaScript patterns
- Add comments for complex logic
- Test with multiple Premiere Pro versions if possible

## Testing
- Test changes in a real Premiere Pro project
- Verify MOGRT compatibility
- Test subtitle injection functionality
