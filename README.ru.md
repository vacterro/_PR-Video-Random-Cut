# PR Video Random Cut

Расширение CEP Adobe Premiere Pro для случайного размещения видеоклипов с взвешенным выбором и поддержкой субтитров. Автоматически заполняет пробелы в последовательностях с интеллектуальным выбором клипов.

## Версия
0.0.1

## Возможности
- **Случайное размещение клипов**: Интеллектуально выбирает и размещает видеоклипы из бинов
- **Взвешенный выбор**: Настройка вероятностей для разных категорий клипов
- **Поддержка субтитров**: Внедрение SRT субтитров с MOGRT шаблонами
- **Обнаружение пробелов**: Автоматически находит и заполняет пробелы в последовательностях
- **Кастомный интерфейс**: Панель для конфигурации и управления
- **Мультиязычность**: Локализованный интерфейс с i18n

## Установка
1. Клонируйте этот репозиторий
2. Запустите `install.bat` (Windows) или `install.ps1` (PowerShell)
3. Перезапустите Adobe Premiere Pro
4. Доступ к расширению через Window > Extensions > machine_asylum YT Tool

## Использование
- Откройте проект Premiere Pro с видеоклипами в бинах
- Выберите последовательность с пробелами для заполнения
- Настройте веса и параметры в панели
- Нажмите "Run" для автоматического заполнения пробелов случайными клипами
- Используйте функции субтитров для внедрения заголовков

## Структура файлов
- `host/` - ExtendScript бэкенд (index.jsx, lib/)
- `client/` - HTML/CSS/JS фронтенд
- `CSXS/` - Манифест расширения
- `assets/` - MOGRT шаблоны и ресурсы
- `icons/` - Иконки расширения

## Конфигурация
- Настройки весов через интерфейс панели
- MOGRT шаблоны в папке assets
- Выбор языка в интерфейсе

## Требования
- Adobe Premiere Pro CC 2017 или новее
- CEP runtime 7.0 или выше
